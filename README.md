# LT-Hearts - Mod do Minecrafta

## Opis
**LT-Hearts** dodaje nad glowami graczy czytelne paski serc oraz opcjonalne animacje obrazen, dzieki czemu szybciej oceniasz stan walki PvP. Mod dziala po stronie klienta i oferuje proste GUI do konfiguracji.

## Funkcje
- Wyswietlanie serc nad innymi graczami z wyrownanym ukladem.
- Obsluga pelnych i polowicznych serc, a przy wiekszej liczbie serc - zwarty zapis.
- Animowane wskazniki obrazen (zanikajace etykiety) z oznaczeniem ciosow krytycznych.
- Limit zasiegu renderowania serc oraz regulowany offset w pionie.
- Przelaczniki: pokazywanie serc i animacji obrazen.
- GUI ustawien oraz komendy klienta.
- Automatyczny zapis konfiguracji do pliku JSON.
- Opcjonalna reklama serwera w liscie multiplayer (ustawienie `adsEnabled`).

## Komendy
| Komenda | Opis |
| --- | --- |
| `/lth` | Informacje o modzie |
| `/lth pomoc` | Lista komend |
| `/lth settings` | Otwiera GUI ustawien |
| `/lth config save` | Zapisuje konfiguracje |
| `/lth config reload` | Przeladowuje konfiguracje |

## Instalacja
1. Pobierz wersje moda zgodna z Twoja wersja Minecrafta.
2. Umiesc plik `.jar` w katalogu `mods` w folderze Minecrafta.
3. Uruchom gre i skonfiguruj ustawienia.

## Konfiguracja
Plik konfiguracyjny:
`.minecraft/config/LT-Mods/LT-Hearts/lth-config.json`

Dostepne ustawienia m.in.:
- `showHearts` - wlaczanie/wylaczanie wyswietlania serc.
- `showDamageAnimation` - wlaczanie animacji obrazen.
- `extraYOffsetPixels` - dodatkowy offset w pionie.
- `maxRenderDistanceBlocks` - maksymalny dystans renderowania serc.
- `adsEnabled` - opcjonalna funkcja polecania serwera.
